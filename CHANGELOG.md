# Changelog

## 1.0.0 — Initial public release

- 21 horror encounters with rarity weighting
- Classic RUN / HIDE / FIGHT gameplay
- Encounter-specific special choice sets
- Victim-only interactive Discord buttons
- Automatic random hunts with configurable channel and timing
- Player statistics, survival streaks, leaderboard, encounter stats, and per-encounter player stats
- Rare fake-out appearances
- Curated lore profiles for all 21 encounters
- Optional Gemini scene writing with automatic built-in fallback
- VHS-style dynamic hunt cards
- Full-scene auto-fitting card text
- Stable card behavior after player choices
- `/slasher setup` server dashboard
- `Slasher Protected` opt-out role support
- Local SQLite persistence
- Windows helper scripts
- Google Cloud 24/7 hosting guide
